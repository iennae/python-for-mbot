    ➕ How to Add a New Mission

    Adding or reordering a mission requires zero HTML or JavaScript editing—all mission ordering and file associations live in missions/missions.json:

    1. Copy missions/TEMPLATE.md, missions/template_mission.py, and missions/test_template_mission.py to descriptive, unnumbered filenames (e.g., missions/servo_arm.md, missions/servo_arm.py, and missions/test_servo_arm.py).

    2. Add your mission object at any position in missions/missions.json with its title, badge, requires_battery, and files: { "story": "...", "starter": "...", "test": "..." }.

    3. Run python scripts/build_site.py (or open scripts/build_site.py in Thonny and press ▶ Run) to regenerate site/missions_data.js, then refresh this page!
