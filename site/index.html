    ➕ How to Add a New Mission

    Adding a new mission to this website requires zero HTML or JavaScript editing:

    1. Copy missions/template_mission.py to missions/mission_06_your_topic.py and customize the baseline diagnostic and # TODO Field Challenge.

    2. Copy missions/TEMPLATE.md to missions/06_your_topic.md and fill in the Story Briefing, Objectives, Systems Check, Hints, Success Metrics, and Debrief table.

    3. Run python scripts/build_site.py (or open scripts/build_site.py in Thonny and press ▶ Run) to regenerate site/missions_data.js, then refresh this page!
